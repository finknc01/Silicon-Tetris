# Level 07 — Tomorrow Is Bigger

## Briefing
The current quarter fits. The board wants a 12-month growth plan.

## Objective
Use sensitivity analysis and headroom rather than one-point forecasts.

## Tasks
Create low/base/high growth scenarios for workload count, model size, concurrency, and SLA. Identify the first resource to saturate in each scenario. Define expansion triggers rather than arbitrary purchase dates.

## Challenge
Make one assumption wrong—model sizes jump, power expansion is delayed, or storage growth exceeds compute growth—and show how the plan adapts.

## Evidence
- scenario table
- bottleneck-by-quarter chart/data
- expansion trigger list
- uncertainty notes

## Victory condition
The model answers “what breaks first if our forecast is wrong?”
